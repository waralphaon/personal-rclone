Personal rclone privacy policy

I use Personal rclone on my own computer to access my Google Drive. Rclone uses Google authorization credentials to list file names and metadata, read file contents and send file changes to Google Drive.

Rclone stores authorization credentials and cached file content locally on my computer. The desktop setup exchanges Drive data with Google for these file operations. I do not use this data for advertising, sell it, or share it with other services.

I can revoke the app’s access in my Google Account and remove its local credentials and cached files. Revoking access does not delete the original files in Drive.
